# ADR 001 — Separate public website and internal OS
Status: proposed, pending infrastructure approval.
Context: public static website cannot safely host confidential client data or server secrets.
Decision: private OS repository and authenticated application; retain public site for marketing and intake. Start modular monolith rather than distributed services.
Consequences: separate deployment and access controls; integration requires authenticated boundary. Hosting, database, identity provider and costs remain undecided. Alternatives: public static storage (rejected for confidentiality), microservices (deferred for complexity).
