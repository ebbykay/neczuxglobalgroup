# Verification and release protocol
Traceability: R01/R02 auth integration and negative tests; R03 validation/persistence; R04/R05 quote calculation and state transitions; R06 project linkage; R07/R08 decimal totals, duplicate and overpayment rejection; R09 audit integration; R10 restore drill; R11 reconciliation. All OS tests pending implementation. Website CI checks links and JS syntax only.
Release gates: passing unit/integration/end-to-end tests, dependency and secret review, migration rehearsal, rollback procedure, access control tests, synthetic lead-to-cash demonstration, owner approval for live data. Record commit, environment, test evidence, known defects and release decision. Post-release smoke test and monitor. Roll back application to prior known-good release; database rollback requires tested migration or restore plan.
