# Security and privacy baseline
Threats: unauthorised access, insecure direct object references, credential leakage, injection, duplicate payment recording, data loss, public exposure. Controls: private repo, managed identity or reviewed auth, server-side role checks, parameterised queries, CSRF protection where applicable, TLS, secret store, minimal data, encrypted backups, audit events and dependency review. Never store client records or secrets in public GitHub. Define incident response: contain, preserve evidence, assess impact, notify as required, recover and review. Ghana data protection obligations and provider agreements require review before live processing. No compliance certification claimed.
